# 工作坊備援與縮課規則

## 120 分鐘正常版

完成 CP01、MVP、規格核可、Bug 回報、第一次 commit 與雙人互測。

## 90 分鐘縮短版

- 保留：CP01、MVP、Bug 回報、commit。
- 改為講師示範：GitHub Pages。
- 移到課後：雙人互測與 CP02。

## 60 分鐘緊急版

- 保留：成品先行、CP01、四格 Bug 回報。
- 不現場建立 Repository，改用已準備好的範例 Repository。
- 結尾只要求寫出下一個可驗收改動。

## 技術故障

- GitHub 無法登入：先保存本機檔案與截圖，課後再 push。
- AI 服務不可用：使用講師預先保存的規格回覆與程式碼。
- 網路中斷：所有 checkpoint 與故障檔均可離線執行。
- 超過三分之一學員卡住：停止新增內容，投影共同完成一次。
