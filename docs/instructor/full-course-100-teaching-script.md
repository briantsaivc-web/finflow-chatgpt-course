## 1. 封面

**核心句**：不會寫程式，照樣做出一款真的遊戲。

**建議講法**  
先問學員：「如果現在只能留下這一頁的一句話，你會留下什麼？」再說明：不會寫程式，照樣做出一款真的遊戲。。不要急著進入術語，先讓學員指出這一步對作品有什麼可觀察的改變。

**FinFlow／結業作品案例**  
以學員正在製作的《人生十五回合》為例，把「封面」落到當前版本。

**現場操作**  
1. 打開目前 checkpoint 與瀏覽器。  
2. 只完成「封面」對應的一個小改動。  
3. 重新整理並走一次正常路徑，再刻意走一次錯誤路徑。  
4. 將結果截圖或記錄在驗收表。

**可複製 Prompt**

```text
請先不要寫程式。用三句話復述：我要完成的作品、今天的最小成果、如何判斷它真的完成。
本頁任務：封面。
完成後請提供：完整檔案、變更摘要、人工測試步驟、仍不確定事項。
```

**預期結果**  
學員能用自己的話解釋本頁概念，並交付一個可以實際操作或檢查的成果，而不是只說「AI 已完成」。

**常見卡點**  
- 一次提出太多需求：退回，只留一個可驗收改動。  
- AI 自行補設定：要求列出假設並重新核可。  
- 只看畫面沒走流程：至少完成正常、錯誤兩條路徑。

**驗收標準**  
- [ ] 看得到本頁對作品造成的具體差異。  
- [ ] 能說明預期與實際結果。  
- [ ] 已留下檔案、截圖或 commit 作為證據。
