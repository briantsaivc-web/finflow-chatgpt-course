# 第一課｜15 分鐘讓第一個按鈕動起來

## 目標

產生一個瀏覽器可以直接開啟、有按鈕與分數的單一 HTML 檔案。

## 可直接複製

```text
請幫我製作一個單一 HTML 檔案的小遊戲：
畫面顯示目前分數與一個「完成挑戰」按鈕；每按一次增加 10 分；
達到 100 分時顯示恭喜訊息；可以按「重新開始」歸零。
請直接交付完整 HTML，不要要求我安裝任何工具。
```

## 預期結果

1. AI 回傳完整 HTML。
2. 儲存成 `index.html`。
3. 雙擊後可在瀏覽器開啟。
4. 按鈕可以增加分數，100 分會顯示完成訊息。

## 完成驗收

> 我能在瀏覽器打開檔案，按鈕會改變分數，重新開始會歸零。
