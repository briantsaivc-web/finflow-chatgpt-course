# 單元 0｜先相信自己做得到

## 這不是程式語法課

你不需要先背 HTML、JavaScript 或資料庫語法。你要先學會四件事：

1. 說清楚自己要什麼。
2. 把第一版縮小到真的做得完。
3. 實際玩過，指出哪裡不符合預期。
4. 替每一次成功留下可以回去的版本。

FinFlow 不是按下一個按鈕就自動生成的。它是在真實遊玩、截圖回報、修正錯誤、朋友測試與二十次疊代中長出來的。

## 15 分鐘任務：讓第一個按鈕動起來

把以下內容複製給你正在使用的 AI：

```text
請幫我製作一個單一 HTML 檔案的小遊戲。

需求：
1. 畫面顯示目前分數，初始為 0。
2. 有一個「完成挑戰」按鈕，每按一次增加 10 分。
3. 達到 100 分時顯示「恭喜，你完成第一個作品！」。
4. 有一個「重新開始」按鈕，可以把分數歸零。
5. 使用繁體中文，手機與電腦都能操作。

請直接交付完整 HTML 程式碼，不要要求我安裝任何工具。
交付後請告訴我如何在 Windows 儲存並打開它。
```

## 儲存成檔案

1. 開啟記事本。
2. 貼上 AI 回傳的完整內容。
3. 選擇「另存新檔」。
4. 檔名輸入 `index.html`。
5. 「存檔類型」選擇「所有檔案」。
6. 編碼選擇 UTF-8。
7. 雙擊 `index.html`。

## 完成驗收

- [ ] 瀏覽器能打開畫面。
- [ ] 每按一次增加 10 分。
- [ ] 100 分顯示恭喜訊息。
- [ ] 重新開始會回到 0 分。
- [ ] 關閉瀏覽器後，原始檔仍然存在。

## 如果失敗

不要重來，也不要只說「不能用」。請把畫面截圖，搭配這句話：

```text
我雙擊 index.html，預期看到計分遊戲，實際看到的是附件畫面。
請先判斷最可能的原因，告訴我如何檢查，不要直接增加新功能。
```

## 本單元存檔

建立資料夾 `my-first-game-v01`，把能正常玩的 `index.html` 放進去。

> 你現在還不是因為懂程式而成功；你是因為能描述、執行與驗收而成功。這正是本課最重要的能力。
