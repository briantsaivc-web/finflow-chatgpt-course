# P03｜規格書卡

## 可直接複製

```text
請根據以下已核可的構想、MVP 與三條鐵律，整理成零基礎者也看得懂的規格書。

必須包含：
1. 產品目標與目標使用者
2. 一局的開始、每回合與結束流程
3. 玩家可做的動作
4. NPC 的最小規則
5. 所有資料欄位與第一版內容清單
6. 勝負與計分方式
7. 錢不夠、重複點擊、資料缺漏等例外狀況
8. 明確不做的功能
9. 人工驗收清單
10. 你仍不確定、需要我決定的事項

限制：
- 先不要寫程式。
- 不得自行把「待確認」補成定案。
- 不得加入未列入 MVP 的功能。

【貼上 idea-v01.md 與 mvp-v01.md】
```
