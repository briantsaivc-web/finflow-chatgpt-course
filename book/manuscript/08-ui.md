# 第八章｜畫面不是裝飾，是遊戲的一部分

一個功能存在，不代表玩家找得到；玩家找得到，也不代表理解按下去會發生什麼。UI 的任務不是把畫面裝飾得漂亮，而是讓人知道現在在哪裡、下一步能做什麼、剛才的動作造成什麼結果。

FinFlow 的主畫面與輪盤經過多次版本才逐漸穩定。每一版不是憑空重畫，而是實際玩過後看見新的問題：資訊太擠、按鈕太遠、不同縮放比例跑版、新手一次看到太多進階資料。

最有效的溝通不一定是專業設計稿。一張手繪、一個 Excel 方格配置，或在截圖上圈選位置，都比「左邊一點、漂亮一點」精準。

UI 改版要一次只處理一層：先決定哪些資訊重要，再調位置尺寸，再改文字，最後才處理配色裝飾。每次都要明確要求不得改動卡片資料、亂數、NPC 與勝負規則，並在完成後重跑核心驗收。

本章任務是保存改版前截圖、草圖、改版後截圖與邏輯驗收證據，證明畫面變好用，而遊戲仍是同一款遊戲。
