    單元 6｜畫面不是裝飾，是玩法的一部分

    UI 的三層問題

    1. 看不看得懂：目前狀態、下一步與結果是否清楚？
    2. 找不找得到：最常用的操作是否在合理位置？
    3. 會不會太多：新手是否一次看到超過需要理解的資訊？

    FinFlow 的主畫面與輪盤經過多次調整才定型。這不代表前面全部做錯，而是實際遊玩後才看得到資訊壓力與操作距離。

    先畫草圖再改

    你可以使用紙筆、Excel 方格或直接在截圖上畫箭頭。重點不是美術，而是讓 AI 不必猜「左邊一點」「大一些」究竟是什麼。

    一次只改一層

    建議順序：

    1. 資訊層級：哪些必須先看到？
    2. 位置與尺寸：按鈕、狀態、遊戲區怎麼安排？
    3. 文字：名稱、說明與錯誤訊息是否白話？
    4. 配色與裝飾：最後才處理美感。

    改畫面時保護遊戲規則

    使用 P05 UI 改版卡，明確要求：

    • 不動卡片資料與數值
    • 不動 NPC、亂數與勝負規則
    • 完成後重跑核心驗收

    漸進揭露

    初級玩家只顯示必要資訊；進階玩家再開啟詳細報表或操作。不要要求每位新手一開始就理解整套系統。

    螢幕檢查

    • 桌機正常寬度
    • 瀏覽器縮放 80%／100%／125%
    • 手機直向
    • 長文字與大數字
    • 按鈕連點與視窗捲動
